## 🌟 Key Features

- **Modern & Responsive Design:** Dark slate/cyan aesthetic, glassmorphic UI, responsive layouts for all device screens.
- **Dynamic Particle Backdrop:** HTML5 Canvas interactive particle constellation.
- **Audio Synthesizer:** Micro-tone sound feedback powered by Web Audio API (with toggle mute/unmute).
- **Interactive Terminal:** Built-in command line interface supporting commands: `help`, `about`, `brand`, `projects`, `skills`, `socials`, `contact`, `clear`.
- **Adaptive Avatar Frame:** Interactive shape framing (Circle, Rounded Squircle, Hexagon, and Natural Fit) with local persistence.
- **Savor of Baltistan Brand Showcase:** Dedicated spotlight on Himalayan Shilajit with direct integration to the [official Facebook Page](https://www.facebook.com/savorofbaltistan/).
- **Project Dossier Modals:** Interactive viewports showcasing hands-on learning projects and GitHub repositories.
- **Contact Utility:** Direct message form and one-click email copy utility.

## 🚀 Deployment to GitHub Pages

### Quick Web Deployment (No CLI Needed — 60 Seconds):

1. Go to [GitHub.com/new](https://github.com/new).
2. Name the repository:
   ```text
   shoaibhassan10.github.io
   ```
3. Set the visibility to **Public**.
4. Click **Create repository**.
5. Click **"upload an existing file"** and drag all files from this folder (`index.html`, `style.css`, `script.js`, `assets/`, `README.md`, `.gitignore`).
6. Click **Commit changes**.
7. In a few seconds, your portfolio will be live at:
   ```text
   https://shoaibhassan10.github.io/
   ```

### Custom Domain with GitHub Student Developer Pack:
1. Claim your free `.me` domain from **Namecheap** or **Name.com** via the [GitHub Student Developer Pack](https://education.github.com/pack).
2. Go to your repository **Settings > Pages > Custom domain**.
3. Enter your domain (e.g., `shoaibhassan.me`) and enable **Enforce HTTPS**.
